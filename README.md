# Fancy Keyboard

A macOS menu bar app that types your clipboard into whatever field you point it at, with human-looking rhythm: variable pacing, pauses after punctuation, occasional hesitations, and typos that get backspaced and corrected.

Repository: https://github.com/sulavtimsina/TypeLikeHuman

## Layout

- `project.yml` — XcodeGen spec for the single macOS app target.
- `files/AppDelegate.swift` — menu bar item, menu, and permission checks.
- `files/TypingEngine.swift` — the timing, typo, and key-emission logic.
- `files/HubstaffCountdown.swift` — the second menu bar item: a 10-minute countdown that stops the Hubstaff timer at zero via Hubstaff's scripted control CLI.
- `files/TypeCLI.swift` — `typehuman`, a command line front end to the same engine, for other tools to call.
- `build-cli.sh` — builds `typehuman` with plain swiftc, no Xcode project needed.
- `files/BUILD.md` — how to generate the project, build, grant Accessibility, and where to tune behaviour.

`FancyKeyboard.xcodeproj` and `FancyKeyboard/Info.plist` are generated by `xcodegen generate` and are not checked in — don't edit them by hand.

## Quick start

```sh
brew install xcodegen          # if you don't have it
xcodegen generate
xcodebuild -project FancyKeyboard.xcodeproj -scheme FancyKeyboard -configuration Debug build
```

Then grant Accessibility in System Settings → Privacy & Security → Accessibility. See `files/BUILD.md` for the details and the gotchas.

## The `typehuman` command

The same engine, driven from a terminal, so scripts can ask for text to be typed instead of clicking the menu bar icon. Build it once:

```sh
./build-cli.sh                 # -> bin/typehuman
```

```sh
typehuman --text "hello there"           # types it after a 3 second pause
typehuman --delay 5 --wpm 60 < answer.txt   # text from stdin
```

Flags: `--text` (otherwise stdin), `--delay` seconds of silence before the first keystroke, `--wpm`, `--typos` (0 to 0.3), `--jitter`, `--hesitation`, `--no-fix-indent`.

Editors that auto-indent (HackerRank, VS Code, CodeMirror, Monaco) insert leading whitespace of their own when you press Return, which stacks with the indentation already in the text and walks the code to the right one line at a time — a staircase, and for Python a different program. So by default every newline is followed by a select-back-to-line-start: the next character typed replaces the whole selection at once, leaving exactly the indentation the text asked for, and an empty selection changes nothing where the editor added none. `--no-fix-indent` types the text byte for byte instead. The menu bar app is unaffected: `Profile.clearAutoIndent` defaults to off, and only the CLI turns it on. Whatever has keyboard focus when the delay runs out receives the text, so the delay is there for clicking into the target field. SIGTERM or Ctrl-C aborts it, during the pause or mid-word, the way Escape does in the app.

Exit codes tell the caller what went wrong: 0 typed it all, 2 aborted, 3 secure input was on so macOS dropped the keystrokes, 4 no Accessibility permission, 64 bad usage. Accessibility belongs to whichever app runs the binary — a terminal, or a script started from one — not to `typehuman` itself, so a terminal that already has the permission needs no new grant. Secure input is checked at the last moment rather than at launch, because the focused app (and therefore the answer) usually changes during the delay.

Nothing about the rhythm lives in the CLI: it compiles `files/TypingEngine.swift` straight into the binary, so the app and the command always type identically.

`bin/` is a build product and is not checked in.

## Push changes to GitHub

**Whenever changes are made, push them to GitHub.** Don't leave work sitting only on this machine — commit it and push it as soon as a change is done.

```sh
git add -A
git commit -m "Describe what changed"
git push origin main
```

That means after every meaningful edit: a code change, a fix to `project.yml`, an update to the docs. If the work isn't finished yet, still commit and push what works so the remote stays current.
